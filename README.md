# Login and Registration Page

## About
This is a simple frontend Login and Registration Page created using HTML, CSS, and JavaScript.

## Features
- Login form with email and password fields
- Registration form with name, email, and password fields
- Switch between Login and Registration forms
- Responsive styling and background image
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` – Page structure
- `style.css` – Styling and layout
- `script.js` – Form switching functionality
- `nature.jpg` – Background image

## Note
This is a frontend practice project. It does not include backend authentication.
